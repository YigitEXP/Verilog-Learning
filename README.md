# Hardware Design & Verilog Learning Journey

Welcome to my digital logic and hardware design portfolio. I am a Computer Engineering student at Süleyman Demirel University (SDU) with a strong focus on building robust, reliable, and "Bulletproof" systems. My core engineering philosophy revolves around being a **Security-First Software Architect**, and I apply this exact same strict discipline to hardware description languages and FPGA design.

## 🎯 About This Repository

This repository serves as a structured log of my transition from VHDL to Verilog. It contains hands-on experiments, from basic logic gates to complex hardware acceleration concepts. 

**📌 Documentation Architecture:** 
To maintain readability and architectural cleanliness, this repository is highly modular. **Every major project or module resides in its own dedicated folder and contains its own specific `README.md` file.** You can navigate to these sub-folders to view detailed schematic diagrams, timing simulations, and deep-dive technical explanations.
